# Marketing image provenance

`hero-lagos.png` and `hero-lagos-sunset.png` were carried forward from the
earlier Inverge codebase before this repository was replaced with the fresh
implementation. That earlier codebase no longer exists as a separate repository.
The images support the approved African visual direction, but their original
creators, licences, and production-use rights are not recorded here. The owner
must confirm or replace them before a public production launch.
